# 02 — Feature Requirements

## Public Features

- Home
- Browse cars
- Search
- Filters
- Sort
- Brand directory
- Brand-specific car results
- Car details
- About
- Contact
- Login
- Register

## Customer Features

- Register
- Email OTP verification
- Mobile OTP verification
- Login
- Logout
- Forgot password
- Reset password
- Profile
- Edit profile
- Change password
- Add car
- Edit own listing
- Delete own listing
- My listings
- Favorites
- Buyer/seller inquiries
- Notifications
- Listing status visibility

## Admin Features

- Admin login
- Dashboard
- User management
- Brand management
- Listing management
- Listing approval/rejection
- Report management
- Basic statistics

## Authentication Requirements

- Password hashing with bcrypt
- JWT authentication
- Protected routes
- Role-based authorization
- OTP verification
- OTP expiration and attempt limits
- Password recovery

## Search Requirements

Search by:

- Brand
- Model
- Keyword
- Location

Filter by:

- Price
- Brand
- Model
- Year
- Fuel
- Transmission
- Kilometers
- Condition

Sort by:

- Price low to high
- Price high to low
- Newest
- Oldest

## Listing Requirements

A listing includes:

- Brand
- Model
- Variant
- Year
- Price
- Fuel type
- Transmission
- Kilometers
- Color
- Location
- Description
- Images
- Condition

Listings should have an approval lifecycle before publication.

## UX Requirements

- Responsive navigation
- Loading states
- Empty states
- Error states
- Toast notifications
- Delete confirmation
- Accessible forms
- Mobile-friendly layouts
