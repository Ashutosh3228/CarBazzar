# 09 — UI/UX Design

## Design Direction

CarBazaar should feel:

- Modern
- Clean
- Professional
- Automotive
- Trustworthy
- Easy to navigate

Avoid excessive animation, clutter and unnecessary features.

## Logo

Create a simple automotive logo for:

**CarBazaar**

It should work in:

- Navbar
- Footer
- Favicon
- Login/register pages
- Mobile header

Use a placeholder asset if a final logo is not supplied.

## Colors

Define a consistent primary accent, neutral background, text colors, success, warning and error states. Keep the palette limited.

## Typography

Use a modern readable sans-serif font with clear heading hierarchy.

## Components

Document reusable components:

- Navbar
- Footer
- CarCard
- BrandCard
- SearchBar
- FilterPanel
- FormInput
- Button
- Modal
- Toast
- Loader
- EmptyState
- ErrorState
- Pagination

## Responsive Rules

- Mobile: single-column layouts where appropriate
- Tablet: two-column grids where appropriate
- Desktop: three/four-column car grids where appropriate
- Admin sidebar collapses on smaller screens

## Accessibility

- Labels for inputs
- Keyboard-friendly controls
- Visible focus states
- Alt text for meaningful images
- Sufficient contrast
- Clear validation messages

## Login/Register

Use the CarBazaar logo, clean forms, clear OTP status, password visibility control, error messages and links between authentication actions.
